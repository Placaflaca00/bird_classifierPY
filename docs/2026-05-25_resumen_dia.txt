6.3 — Scripts standalone E2E validados
---------------------------------------

scripts/export_dataset.py (~520 lineas)
- Lee DDB approved + descarga audios de S3 + calcula embeddings BirdNET
- Re-generacion FULL cada run (no append) — sincronizado con DDB siempre
- Cache SHA-256 por audio para evitar recompute de los 2590 originales
- Fail-loud si s3_key falta (con prediction_id en mensaje)
- Output: parquet self-contained con audit columns (source, ddb_pk,
  generated_at, git_sha)
- Bug encontrado y arreglado: mix float64 (originales) + float32 (nuevos)
  rompia pyarrow -> normalize todo a float32 antes de escribir
- Resultado: 2691 filas (2590 original + 101 annotator), cache 100% HIT
  en re-run, 11.1 MB output

scripts/train.py (~400 lineas)
- Standalone, reusa BirdClassifier de src/models/classifier.py
- Hyperparams hardcoded a defaults wa-drop3-v1 (aisla efecto del dataset
  como variable confounding — no McNemar)
- Determinismo robusto: torch.use_deterministic + cuDNN flags + CUBLAS
- Sanity checks pre-train: D20 invariant (cero annotator en hold-out),
  shape 1024, sin NaN, warn especies <10
- Run naming: retrain-<ts>-<git_sha[:7]>
- Resultado smoke (2 epochs): pipeline E2E OK
- Resultado full (50 epochs, best epoch=22): val_macro_f1=0.909,
  hard_acc=0.8173, hard_macro_f1=0.7929

tests/test_train_equivalence.py (~150 lineas)
- Garantiza scripts/train.py y src/training/train.py producen ckpts
  identicos sobre mismo subset + misma seed
- Bug REAL detectado por el test al primer run: scripts/train.py pasaba
  generator=g local al DataLoader, legacy usa global RNG -> divergencia
  legacy macro_f1=0.084 vs new=0.217. Fix: quitar generator local.
- Tolerancia atol=1e-4 (logica core, no determinismo extra)
- Lesson learned ORO para CV: el test atrapo bug semantico que un code
  review humano facilmente no atrapa

scripts/evaluate.py (~470 lineas)
- McNemar mid-p (Fagerland et al. 2013, citado en docstring) —
  superior a Edwards CC + binomial exacto
- Edge case b+c==0: predicciones identicas -> p=1.0, no promover
- Bootstrap CI 1000 resamples sobre pares pareados — segunda senal
  independiente de McNemar
- Macro F1 floor (-0.5pp) — anti regresion sigilosa en clases minoritarias
- Ejecutado contra candidato actual:
    delta_acc_pp = +0.48 (< 1.0 threshold)
    p_value McNemar = 0.7905 (>> 0.05)
    delta_macro_f1_pp = -1.31 (< -0.5 floor)
    bootstrap CI delta_acc_pp = [-2.40, +3.85] cruza cero
- should_promote = FALSE con 3 razones independientes
- Esto demuestra que el threshold funciona como GATE REAL, no
  rubber-stamp. El sistema NO se auto-promueve por ruido.
